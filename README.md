BasicStar Word Processor - User Manual
==================================
 
NAVIGATION
----------
Arrow keys          Move cursor one character / line
Home                Jump to start of current line
End                 Jump to end of current line
Page Up             Scroll up one screen
Page Down           Scroll down one screen
 
EDITING
-------
Type normally       Insert text at the cursor position
Backspace           Delete the character to the left of the cursor.
                    At the start of a line, joins it to the line above.
Delete              Delete the character under the cursor.
                    At the end of a line, joins it to the line below.
Enter               Start a new line at the cursor position.
 
SELECTING TEXT
--------------
Shift + Arrow       Begin or extend a selection.
                    The anchor is set where Shift is first pressed;
                    the cursor marks the other end.
Escape              Cancel the current selection.
 
While text is selected:
  - Typing replaces the selection with the new character.
  - Backspace or Delete removes the selection.
  - Enter replaces the selection with a new line.
 
CUT, COPY AND PASTE
--------------------
Ctrl+C              Copy the selected text to the internal clipboard.
Ctrl+X              Cut the selected text (copy then delete).
Ctrl+V              Paste the clipboard contents at the cursor position.
                    Multi-line pastes are supported.
 
Note: the clipboard is internal to the word processor and is not
shared with Windows or other applications.
 
FILE OPERATIONS
---------------
Ctrl+S              Save the current document.
                    If the document has not been saved before, you
                    will be prompted to enter a filename.
Ctrl+O              Open a file. You will be prompted for the filename.
                    Type the full path if the file is not in the
                    current directory (e.g. C:\docs\notes.txt).
Ctrl+N              Start a new empty document.
Ctrl+Q              Quit the word processor.
 
THE STATUS BAR
--------------
The second-to-last line shows:
  - The current filename (or [untitled] if not yet saved).
  - An asterisk (*) if there are unsaved changes.
  - The current line number (Ln) and column number (Co).
  - A reminder of the main keyboard shortcuts.
 
TIPS
----
- There is no undo yet, so save often with Ctrl+S.
- Lines longer than 80 characters will be cut off on screen,
  but the full text is preserved in the file.
- The document can hold up to 5000 lines.
