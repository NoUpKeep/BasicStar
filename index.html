BASICSTAR WORD PROCESSOR QB64-PE

BasicStar_

A full-screen word processor for QB64-PE, inspired by the classics of the 1980s.

QB64-PE Windows Linux macOS Public Domain

BasicStar brings back the feel of early word processors — the kind that ran on machines you could actually understand. It runs in 80×25 text mode, edits plain text files, and gets out of your way. Named in tribute to WordStar and written entirely in BASIC.

// FEATURES

Full-screen 80×25 text mode
Shift+Arrow text selection
Cut, copy & paste
Save & open plain text files
Unsaved changes indicator
Line & column display
Up to 5,000 lines per document
No external dependencies

// GETTING STARTED

1. Download BasicStar.bas from the repository.
2. Open it in QB64-PE.
3. Press F5 to compile and run.

No libraries, no dependencies. Just BASIC.
